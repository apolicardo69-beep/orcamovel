# OrcaMóvel 🪵

Agente IA especialista em orçamento de móveis planejados e marcenaria técnica de alto padrão.

## Recursos
- 📐 Análise automática de plantas, cortes e cotas de projetos técnicos (PDF/JPG/PNG).
- 🚀 Suporte a documentos multi-páginas com renderização otimizada.
- 📱 Interface 100% responsiva para desktop e dispositivos móveis.
- 📄 Geração instantânea de relatório de orçamento técnico em PDF.
- 🧠 Sistema de aprendizado contínuo com regras de precificação e exemplos reais configuráveis.

## Deploy na Vercel

### Configuração da Chave da OpenRouter (Servidor)
No painel da Vercel → **Project → Settings → Environment Variables**:
- `OPENROUTER_API_KEY` = `sk-or-...`

## Desenvolvimento Local
```bash
npm install
npm run dev
```

Acesse em: `http://localhost:5173`
